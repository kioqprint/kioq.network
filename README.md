# KIOQ.network

منصة جزائرية لتوزيع تعبئات الهاتف والإنترنت على تجار التجزئة.

## حالة البناء

المستودع يبدأ من أساس نظيف. أول مرحلة هي نموذج واجهة إدخال التعبئات باللغة العربية (RTL).

## تشغيل النموذج الأولي

افتح الملف `prototype/recharge.html` مباشرة في متصفح حديث.

> هذا نموذج واجهة فقط: لا ينفذ تعبئات حقيقية، ولا يتصل بـ OneClick، ولا يحفظ البيانات على خادم. بيانات السجل وجهات الاتصال المعروضة تجريبية.

## مبادئ ثابتة

- حساب المالك الرئيسي هو حساب الجملة الوحيد.
- الحسابات الأخرى حسابات تجار تجزئة فقط.
- المواطن النهائي لا يملك حساباً في المنصة.
- OneClick API ومفاتيحه تبقى في الخادم فقط.
- تكلفة OneClick وهوامش المالك معلومات داخلية لا تظهر للتاجر.
- لا تُنفذ التعبئات الحقيقية دون تحقق مركزي من الخادم.

## البنية المستهدفة

- ASP.NET Core / .NET
- Windows: WPF + MVVM
- PostgreSQL مركزي وSQLite محلي حسب حدود العمل دون اتصال
- Modular Monolith
- تكامل OneClick من الخادم فقط

## المرحلة الأولى

واجهة التعبئة:
- Djezzy وOoredoo وMobilis.
- IDoom Fibre وIDoom 4G في واجهتين منفصلتين.
- تحقق مبدئي من بادئات الأرقام.
- جهات اتصال واقتراحات أرقام سابقة خاصة بالتاجر.
- شحن عادي وعروض مفعّلة.
- مبالغ سريعة.
- سجل تعبئة تفصيلي.
- فصل صلاحيات ومعلومات المالك عن التاجر.
